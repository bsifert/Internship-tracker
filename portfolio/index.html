A web app that turns an 85-company internship spreadsheet into a ranked to-do list. It tells me which application needs attention today, and why.

The problem

My internship search lived in a Google Sheet with 85 companies, each with a research status, priority, deadline, contacts and notes. The sheet could store all of it but couldn’t tell me what to do next. Deadlines slipped past, and follow-ups were easy to forget.

What I built

  • “Do these next” ranking. Every company is scored on overdue deadlines, follow-ups that are due, open postings and postings about to open, weighted by priority. The most pressing item is always at the top.
  • Urgency board and table. A board groups companies by research status. A sortable, filterable table supports multi-select bulk edits.
  • Application history. Every status change is timestamped, so each company has a timeline from first look to offer.
  • Spreadsheet round-trip. Exports to JSON or CSV. Importing a CSV from Google Sheets merges by company name: it updates existing rows, adds new ones, and leaves out-of-file columns alone.
  • No account needed. Data autosaves in the browser. Because that is fragile, the app reminds me to download a backup when the last one gets old.

Safe upgrades for saved data. New fields like posting links and follow-up dates were added after the app was already in use. Every record loaded from storage or from a backup is normalized first, so older saves never crash the newer version.

Cleaning up the original data. The sheet had been exported through a PDF, which cut long notes off mid-sentence. The app detects those rows and flags them to be rewritten.

Automated deploys. A GitHub Actions workflow type-checks, builds and publishes the site to GitHub Pages automatically.
